# Threat model v0 (STRIDE)

Область: платформа CyberSim — API, SPA, БД, LLM-контур, site-service с корпусом, CI. Версия 0 фиксирует границы и главные угрозы; детализация по компонентам — в `backlog_security.md`.

## Активы

| Актив | Почему важен |
|---|---|
| Правила ИБ компании (`security_rules`) | раскрывают внутренние регламенты и слабые места |
| Сценарии и ключ ответов (`risk`, `goal`, `is_phishing`) | обесценивают обучение при утечке |
| Поведение сотрудников (`attempts`, лента событий) | персональные данные, репутационные риски |
| Корпус сайтов и артефактов | инструмент фишинга при выносе наружу |
| Модель и адаптер (веса) | интеллектуальная собственность, стоимость |
| Сессии и учётные записи | доступ ко всем предыдущим активам |

## Акторы и границы доверия

- **Сотрудник** — легитимный пользователь, но может пытаться обойти обучение (накрутка, слив ответов) и любопытствовать (DevTools).
- **Администратор** — доверенный, но с широкими правами; ошибка админа дороже атаки.
- **Аноним из сети** — не должен видеть ничего, кроме страницы входа.
- **Злоумышленник с доступом к репозиторию/CI** — supply chain.
- **Документ-источник** — недоверенный ввод (может содержать prompt injection).

Границы: браузер ↔ API (граница 1), API ↔ БД (2), API ↔ vLLM (3), SPA ↔ site-service через iframe (4), сервер ↔ интернет (5, должна быть закрыта), CI ↔ реестр артефактов (6).

## STRIDE по компонентам

| Компонент | Угроза | Сценарий | Митигация |
|---|---|---|---|
| Вход/сессии | **S**poofing | подбор пароля, перехват cookie | Argon2id, rate limit, `HttpOnly; Secure; SameSite`, MFA админа (ADR-0004) |
| API | **T**ampering | подмена `tenant_id`/`employee_id` в запросе | идентичность только из сессии, IDOR-тесты (ADR-0004, бэклог п. 10) |
| API | **R**epudiation | «я не выбирал это действие» | append-only `attempts` с `attempt_id` и временем (бэклог п. 9) |
| API/БД | **I**nformation disclosure | чтение чужого ящика по id | фильтр по арендатору и сотруднику, 404 вместо 403 |
| Оценка | **I**nformation disclosure | `risk`/`goal` в ответе API | public-DTO, контрактный тест (ADR-0007) |
| Корпус | **I**nformation disclosure | выкачивание сайтов → таблица «host → вердикт» | лимит навигации, world per tenant, `world_secret` вне репозитория (ADR-0005) |
| SPA | **T**ampering / XSS | HTML от LLM или из артефакта исполняется в приложении | артефакты рендерят компоненты; HTML только в iframe с `sandbox`, CSP `script-src 'none'` (ADR-0003) |
| site-service | **S**poofing / SSRF | `?url=http://169.254.169.254/...` | allowlist хостов из реестра, никаких исходящих запросов (ADR-0005, бэклог п. 8) |
| site-service | **D**oS | обход всего корпуса за минуты | лимит запросов на сессию, пагинация, кэш |
| LLM-контур | **T**ampering | prompt injection из текста регламента | правила как data-блок, строгая схема выхода, регресс-набор инъекций (бэклог п. 11) |
| LLM-контур | **E**levation | доступ к `/v1/load_lora_adapter` и админ-эндпоинтам | reverse-proxy с allowlist путей, сеть без публикации порта (бэклог пп. 1–3) |
| БД | **I**nformation disclosure | бэкап без шифрования, чтение дампа | шифрование at rest и в бэкапах, retention (бэклог п. 12) |
| CI | **T**ampering | подмена зависимости, кража токена | pin по digest, `--require-hashes`, gitleaks, минимальные права (бэклог п. 13) |
| Инфраструктура | **D**oS | `n>1`, большие `logprobs`, флуд логина | rate limit, валидация параметров, таймауты (бэклог п. 7) |
| Админка | **E**levation | админ смотрит чужой тенант | RBAC + tenant из сессии, MFA, аудит действий |

## Что сознательно вне области v0

- Защита от физического доступа к серверу и от компрометации ОС.
- Атаки на сам браузер сотрудника (расширения, кейлоггеры).
- Юридическая экспертиза контента (вымышленные бренды) — отдельная задача M9.
- Защита от инсайдера с правами root на сервере.

## Правила пересмотра

1. Модель обновляется при появлении нового компонента (очередь генерации, эмбеддинг-сервис, плагин канала).
2. Каждый пункт `backlog_security.md` ссылается на строку этой таблицы; закрытие — только с тестом или доказательством.
3. Перед релизом (G3) — сверка: нет строки без митигации и митигации без проверки.
